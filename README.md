# Доходы — личный дашборд

Одностраничное приложение для учёта личного дохода. Открывается по ссылке с компьютера и телефона,
данные хранятся в JSON-файле на GitHub. Сборка не нужна: только HTML, CSS и JavaScript.

## Что умеет

- **Виды дохода:** аванс, окончательная зарплата, наличные в кассе завода, дополнительный заработок,
  командировка (суточные).
- **Дата прихода**, **источник дохода** (завод, организация, заказчик) и **способ выплаты** — наличные или безнал.
- **Свои источники:** добавление, переименование и удаление. При переименовании обновляются все записи,
  при удалении записи сохраняются (источник у них очищается).
- **Сводка за период:** общая сумма, наличные, безнал, средний доход в месяц.
- **График по месяцам** за последние 12 месяцев. Месяцы выбранного периода подсвечены, остальные приглушены.
  Клик по столбцу выбирает этот месяц.
- **Структура дохода** по видам с суммами и долями.
- **Фильтры:** период (месяц, прошлый месяц, 3 месяца, год, всё время, свой диапазон), вид дохода,
  способ выплаты, источник, поиск по источнику и комментарию.
- **Список записей** с группировкой по месяцам, редактированием и удалением.
- **Хранение на GitHub** через GitHub API + локальная копия в браузере.
- Работает офлайн: изменения сохраняются на устройстве и отправляются на GitHub, когда появится связь.
- Светлая и тёмная темы, адаптив от 320 px, установка на телефон как приложение (PWA).
- Экспорт и импорт JSON — для резервных копий и переноса данных.

## Быстрый старт на компьютере

Скачайте папку `income-dashboard` и запустите любой статический сервер из неё:

```bash
cd income-dashboard
python -m http.server 8765
```

Откройте http://127.0.0.1:8765 — можно сразу добавлять записи. Пока GitHub не подключён,
данные лежат только в localStorage браузера.

> Открывать `index.html` двойным щелчком тоже можно, но тогда не зарегистрируется service worker
> (офлайн-режим и установка на телефон работают только по `http(s)://`).

## Публикация на GitHub Pages

1. Создайте репозиторий, например `income` (публичный — GitHub Pages для приватных репозиториев
   требует платного тарифа).
2. Загрузите **содержимое** папки `income-dashboard` в корень репозитория, чтобы `index.html`
   лежал в корне. Можно перетащить файлы через веб-интерфейс GitHub или через git:

   ```bash
   git init
   git add .
   git commit -m "income dashboard"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/income.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Build and deployment**.
   Source: **Deploy from a branch**, Branch: **main**, folder: **/(root)**. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:

   ```
   https://ВАШ_ЛОГИН.github.io/income/
   ```

Эту ссылку открывайте на компьютере и телефоне.

## Где хранятся данные

Данные — это файл `data/income.json` (путь можно изменить в настройках). Есть два варианта.

### Вариант A. Всё в одном репозитории

Страница и файл данных лежат в одном публичном репозитории. Просто, но **файл с доходами
доступен всем, кто знает ссылку** на репозиторий. Подходит, если скрывать нечего.

### Вариант B. Отдельный приватный репозиторий для данных (рекомендуется)

1. Создайте **приватный** репозиторий, например `income-data`.
2. В настройках приложения укажите владельца и имя **этого** репозитория.
3. Страница при этом может оставаться в публичном репозитории — она обращается к данным по API
   с вашим токеном.

Так суммы видны только вам (и тем, кому вы дадите токен).

### Токен GitHub

Нужен fine-grained token с правом записи в репозиторий с данными:

1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens**.
2. **Generate new token**.
3. **Repository access → Only select repositories** → выберите репозиторий с данными.
4. **Repository permissions → Contents → Read and write**.
5. Создайте токен, скопируйте его (показывается один раз).

Токен вводится в приложении: **шестерёнка → Токен GitHub**. Он хранится только в localStorage
этого браузера и отправляется только на `api.github.com`. В репозиторий токен не попадает.

Поля в настройках:

| Поле | Пример | Что это |
|---|---|---|
| Владелец | `ivanov` | логин GitHub или организация |
| Репозиторий | `income-data` | репозиторий, где лежит JSON |
| Ветка | `main` | ветка репозитория |
| Путь к файлу | `data/income.json` | путь внутри репозитория |
| Токен | `github_pat_…` | fine-grained token |

Нажмите **Проверить и сохранить**. Приложение проверит репозиторий, ветку и файл:
- если файла нет — создаст его при первом сохранении;
- если файл есть — загрузит записи;
- если записи есть и на устройстве, и в файле — объединит их по id, ничего не потеряв.

На телефоне настройки нужно ввести один раз. Дальше токен хранится в браузере.

## Телефон

1. Откройте ссылку из GitHub Pages в Safari или Chrome.
2. Введите настройки GitHub (шестерёнка).
3. Добавьте страницу на главный экран:
   - **iPhone (Safari):** «Поделиться» → «На экран “Домой”».
   - **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».

Откроется на весь экран, без адресной строки.

## Как пользоваться

- **Добавить** — кнопка справа сверху или «+» на телефоне. Выберите вид дохода, сумму, дату,
  наличные/безнал, при желании источник и комментарий.
- **Период** — чипы над графиком. «Свой период» показывает два поля с датами.
- **График по месяцам** — 12 столбцов, заканчивая месяцем выбранного периода. Клик по столбцу
  переключает дашборд на этот месяц.
- **Фильтры по виду дохода** — можно выбрать несколько.
- **Источник** — можно выбрать из списка или ввести новый прямо в форме записи (кнопка «+» рядом с полем).
  Управление списком — **шестерёнка → Источники дохода**: добавить, переименовать (карандаш) или удалить
  (корзина). Переименование обновляет все связанные записи; при удалении записи остаются, но без источника.
- **Поиск** — по источнику и комментарию.
- **Изменить/удалить** — иконки в строке записи.
- **Статус в шапке**:
  - `Локально` — GitHub не подключён (нажмите, чтобы открыть настройки);
  - `Синхронизировано` — всё сохранено на GitHub (нажмите, чтобы обновить);
  - `Не отправлено` — есть изменения, которые не ушли на GitHub (нажмите, чтобы повторить);
  - `Нет связи` — GitHub недоступен, данные сохранены на устройстве.

Смена темы — кнопка с луной/солнцем. Выбор запоминается.

## Формат данных

`data/income.json`:

```json
{
  "version": 1,
  "updatedAt": "2026-10-20T10:00:00.000Z",
  "sources": ["Завод «Рифей»", "Подработка"],
  "entries": [
    {
      "id": "0f0b0e2e-3a1f-4d7a-9c3e-2b7a1f5d8c11",
      "date": "2026-10-05",
      "type": "advance",
      "amount": 30000,
      "method": "cash",
      "source": "Завод «Рифей»",
      "note": "за первую половину октября",
      "createdAt": "2026-10-05T09:12:00.000Z",
      "updatedAt": null
    }
  ]
}
```

- `type`: `advance` | `salary` | `plant_cash` | `side` | `trip`
- `method`: `cash` (наличные) | `bank` (безнал)
- `date`: `ГГГГ-ММ-ДД`
- `amount`: число (рубли, можно с копейками)
- `sources`: список источников дохода; если его нет, приложение соберёт источники из записей

Файл можно редактировать вручную на GitHub — приложение подхватит изменения после обновления.
Коммит от приложения выглядит как `income: обновление данных …`.

## Резервные копии

**Шестерёнка → Скачать JSON** — сохранит все записи в файл. **Загрузить JSON** — заменит текущие
записи содержимым файла (с подтверждением). История изменений файла также хранится в git
репозитория GitHub.

## Безопасность и ограничения

- Токен лежит в localStorage браузера. На общем компьютере после работы нажмите
  **Отключить GitHub** или очистите данные сайта. Скомпрометированный токен отзовите на GitHub.
- Любой, у кого есть токен, получает доступ к репозиторию с данными. Не передавайте его третьим лицам.
- В публичном репозитории JSON-файл с доходами доступен всем — для приватности используйте
  отдельный приватный репозиторий (вариант B).
- Одновременное редактирование с двух устройств: при конфликте приложение повторяет отправку.
  Последняя запись побеждает; при первичном подключении записи объединяются по id.
- Нет сервера и общей базы: у каждого устройства свой токен и локальная копия.
- GitHub API имеет лимиты (для fine-grained токена — 5000 запросов в час, чего с запасом хватает).

├── index.html              разметка приложения
├── css/style.css           стили, тёмная/светлая темы, адаптив

(GitHub Pages, Netlify, Cloudflare Pages и т. п.).
