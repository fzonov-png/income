Настройки

Хранение на GitHub. Записи лежат в JSON-файле вашего репозитория. Токен хранится только в этом браузере — на телефоне его нужно ввести один раз.
Как получить токен
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access → Only select repositories → выберите репозиторий с данными.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Скопируйте токен (он показывается один раз) и вставьте сюда.
